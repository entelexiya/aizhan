# Как включить управление объектами

Сайт состоит из трёх страниц:

- `index.html` — главная, показывает 3 объекта и кнопку «Весь каталог»;
- `catalog.html` — все объекты;
- `admin.html` — страница, где Айжан сама добавляет и удаляет объекты (адрес `/admin.html`).

Объекты хранятся в Vercel Blob. Пока хранилище не подключено, сайт показывает примеры из `config.js`.

## Что нужно сделать один раз

1. **Залить проект на Vercel.** Vercel → Add New → Project → выбрать репозиторий `entelexiya/aizhan` → Deploy.
2. **Подключить хранилище.** В проекте: вкладка **Storage** → Create Database → **Blob** → Connect.
   Vercel сам добавит переменную `BLOB_READ_WRITE_TOKEN`.
3. **Задать пароль админки.** Settings → **Environment Variables** → добавить:
   - Name: `ADMIN_PASSWORD`
   - Value: пароль, который будет знать только Айжан
   - Применить ко всем окружениям (Production, Preview, Development).
4. **Передеплоить.** Deployments → у последнего деплоя меню «…» → Redeploy.

## Как Айжан меняет объекты

1. Открывает `https://<адрес сайта>/admin.html`.
2. Вводит пароль.
3. Для каждой квартиры заполняет: ссылку на объявление, фото (можно снять или выбрать с телефона), заголовок, ЖК и район, комнаты, площадь, этаж, цену, метку.
4. Нажимает «Сохранить и опубликовать». Изменения сразу видны всем на сайте и в каталоге.

Кнопки ↑ и ↓ меняют порядок: первые три объекта из списка попадают на главную.

## Важно про безопасность

- Пароль хранится только в переменной `ADMIN_PASSWORD` на Vercel. В коде его нет.
- Без пароля ничего сохранить нельзя, даже если кто-то найдёт адрес `/admin.html`.
- Пароль не должен повторять пароли от почты, Instagram и банка.
- Если пароль утёк — поменяйте значение `ADMIN_PASSWORD` и передеплойте, старый сразу перестанет работать.

## Локальная проверка

Открытый с диска `index.html` работает, но объекты берутся из `config.js`, а админка не сохраняет —
запросы к `/api/...` есть только на Vercel. Чтобы проверить всё локально: `npx vercel dev`.
